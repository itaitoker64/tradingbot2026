🚀 הרצה מהירה
# 1. סביבה וירטואלית
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 2. הגדרות
cp .env.example .env      # מלא מפתחות API

# 3. Backtest על AAPL + MSFT
RUN_MODE=backtest python main.py AAPL MSFT

# 4. Paper trading (בלי כסף אמיתי)
RUN_MODE=paper python main.py AAPL

# 5. Live — רק לאחר בדיקות מקיפות!
RUN_MODE=live EXECUTE_LIVE=true python main.py AAPL
🛡️ חוסן שגיאות

כל סוכן עטוף ב-safe_evaluate() — אם סוכן זורק חריגה (רשת, timeout, API), הוא מדורג ל-50 (נייטרל) ומתועד ב-log, במקום לקרוס את כל ה-desk. הבוט ממשיך לפעול עם הסוכנים הזמינים.

⚠️ אזהרה: זהו scaffold הנדסי בלבד — לא עצה פיננסית ולא מערכת רווחית מוכחת. המחבר אינו יועץ ההשקעות שלך. הרץ backtest מקיף, הבן כל שורת קוד, ולעולם אל תפעיל הון חי שאינך יכול להרשות לעצמך להפסיד.
